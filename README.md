## 📌 1. תיאור הבעיה והפתרון (חצי עמוד להערכה)

### הבעיה
חיפוש משרות תוכנה ופיתוח דורש ממעסיקים ומחפשי עבודה לסנן מאות מודעות, לבדוק דרישות טכנולוגיות, לוודא רמת ניסיון מתאימה, ולעדכן מילות חיפוש שוב ושוב באופן ידני.

### מה האג'נט עושה?
**Job Scout AI** הוא סוכן אוטונומי שמקבל את פרופיל המועמדת (כישורים, תפקידים, מיקום ורמת ניסיון) ומנהל לולאת חיפוש והערכה חכמה:
1. **שליפת נתונים מ-APIs ציבוריים:** קריאה לכלי חיפוש חיצוניים (`Remotive` ו-`Arbeitnow`) לקבלת מאות מודעות בזמן אמת.
2. **ניתוח ודירוג דטרמיניסטי ב-Python:** חישוב ציון התאמה (0-100) לכל משרה בהתאם לטכנולוגיות, ניסיון, מיקום ותאריך.
3. **קבלת החלטות והערכת AI:** מודל LLM חיצוני (`Groq` - `llama-3.1-8b-instant`) בוחן את התוצאות, מנמק את ההתאמות, ומחליט באופן אוטונומי האם **לעצור** (כי הושג היעד) או **להרחיב את החיפוש** (הוספת מילות מפתח משיקות).
4. **חסינות ומנגנון גיבוי (Fallback):** אם חלה בעיית רשת או מגבלה במודל, האג'נט עובר אוטומטית למצב גיבוי ומציג את התוצאות המובילות של מנוע Python ללא קריסה.

## 🎯 3. התאמה מלאה לדרישות המבדק

| דרישת המבדק | מימוש ב-Job Scout AI |
| :--- | :--- |
| **1. קבלת מטרה** | המשתמשת מגדירה כישורים, תפקידים, רמת ניסיון ומיקום מבוקש. |
| **2. שימוש בכלי חיצוני** | קריאה ל-APIs ציבוריים חיצוניים (Remotive API & Arbeitnow API) לשליפת נתונים בזמן אמת. |
| **3. שימוש במודל AI חיצוני** | מודל ה-LLM ב-Groq מנתח את התוצאות, מחזיר נימוקי התאמה ופערים, ומקבל החלטת המשך. |
| **4. שימוש בכלי Python** | מנוע חישוב דטרמיניסטי ב-Python המבצע נרמול נתונים, סינון וציון התאמה משוקלל. |
| **5. קבלת החלטות** | המודל בוחר בין `stop` (עצירה) לבין `broaden` (הרחבת מילות החיפוש לסבב הבא). |
| **6. בחינת התוצאה** | האג'נט סופר כמה משרות איכותיות ואינדיקטיביות נמצאו בכל סבב. |
| **7. תנאי עצירה** | מוגדר מראש: מציאת לפחות 4 משרות איכותיות (ציון 45+) או הגעה למגבלת סבבים (Max Rounds). |
| **8. טיפול בשגיאות וחסינות** | מנגנון Try-Except מלא למניעת נפילות SSL, בעיות תקשורת ומגבלות API (Python Fallback). |
| **9. שקיפות ושליטה** | הצגת עקבות החלטה (Trace) מלאים, מקורות המידע וקישורים ישירים. |
