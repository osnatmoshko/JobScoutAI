Job Scout AI — התחלה מהירה
==========================

1. חלצי את כל קובץ ה-ZIP לתיקייה רגילה במחשב.
2. ודאי שמותקן Python 3.10 ומעלה: https://www.python.org/downloads/windows/
   במהלך ההתקנה סמני Add Python to PATH.
3. לחצי פעמיים על הקובץ: הפעלה_בקליק.bat
   בפעם הראשונה נדרשת גישה לאינטרנט כדי להתקין את הספריות. זה יכול לקחת כמה דקות.
4. כשהאתר נפתח, הכניסי בשדה "מפתח Groq API" מפתח שיצרת ב- https://console.groq.com/keys
   זה חייב להיות מפתח Groq, ולא מפתח Gemini/Google.
5. מלאי את פרטי החיפוש ולחצי "הפעלת הסוכן".

חשוב:
- אין צורך להכניס מפתח לקובץ או לשלוח אותו לאף אחד.
- בלי מפתח Groq תקין וחיבור לאינטרנט, שלב ה-AI לא יעבוד.
- מקורות המשרות הם APIs ציבוריים של Remotive ו-Arbeitnow. הם מתמקדים בעיקר במשרות מרחוק/אירופה ולא מבטיחים כיסוי מלא של ישראל.
- בדקי שהתקבלו תוצאות אמיתיות ושקישורי המשרות נפתחים לפני ההגשה.
- לא מעלים מפתח API ל-GitHub.

אם חלון ההפעלה נסגר או מופיעה שגיאה, צלמי/העתיקי את הודעת השגיאה (בלי מפתח API) ושלחי אותה לעזרה.
